運営募集

MyshCraftを一緒につくってくれる運営メンバーを募集しています。Admin以外の役職が募集対象です。

現在募集中：Moderator / Developer / Editor / Builder　｜　Adminは募集対象外です。
MODERATOR募集中

Moderator

Java版。一部例外除く
サーバー内のルール確認、プレイヤー対応、コミュニティの環境づくりなどを担当します。

DEVELOPER募集中

Developer

ある程度知識ある方
サーバーの機能・プラグイン・システム面などを担当します。

EDITOR募集中

Editor

統合版OK・初心者大歓迎
サイトや告知、文章・画像などの編集や情報発信を担当します。

BUILDER募集中

Builder

統合版OK・初心者大歓迎
街、施設、景観などMyshCraftの世界づくりを担当します。

ADMIN現在の管理担当

Admin

サーバー全体の管理・方針決定を担当します。今回の募集対象ではありません。
